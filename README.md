# Mutual-Fund-Performance-Analysis-and-Investment-Insights-

## Project Overview

       An end-to-end Data Analytics project that transforms raw mutual fund data into actionable investment insights using Python, Exploratory Data Analysis (EDA), and Data Visualization.


# 🎯 Business Problem

Financial datasets contain millions of records that are difficult to interpret manually. Investors and financial analysts need data-driven insights to understand:

- Which mutual fund categories dominate the market?
- How investor inflows and redemptions impact fund performance.
- Which schemes manage the highest Assets Under Management (AUM).
- Hidden trends and outliers affecting investment decisions.

This project answers these questions through Exploratory Data Analysis (EDA).


# 🎯 Objectives

- Clean and preprocess raw mutual fund data.
- Perform univariate, bivariate, and multivariate analysis.
- Identify trends in investor behavior.
- Analyze relationships between important financial metrics.
- Detect outliers affecting mutual fund performance.
- Generate business insights for better investment decisions.


# 📂 Dataset Information

The dataset contains information about Indian Mutual Fund schemes including:

| Feature | Description |
|----------|-------------|
| Date | Reporting date |
| Scheme Name | Name of Mutual Fund Scheme |
| Scheme Type | Type of Scheme |
| Scheme Category | Category of Fund |
| Number of Schemes | Total schemes available |
| Number of Folios | Investor accounts |
| Fund Mobilized | Amount invested |
| Repurchase/Redemption | Amount withdrawn |
| Net Inflow/Outflow | Difference between investments and withdrawals |
| Net AUM | Net Assets Under Management |
| Average Net AUM | Average Assets Under Management |

# 🔍 Key Insights

- Income/Debt Oriented schemes dominate the mutual fund market with the highest number of schemes.
- Net Assets Under Management (AUM) show a strong positive relationship with Average Net AUM.
- Investor folios generally increase with higher Assets Under Management.
- Several financial variables contain significant outliers, indicating exceptionally large funds and investment movements.
- Most financial variables exhibit right-skewed distributions, suggesting a small number of schemes contribute disproportionately to market size.


# 💼 Business Recommendations

- Monitor categories with consistently high investor inflows to identify potential growth opportunities.
- Investigate extreme outliers separately, as they may represent high-performing or specialized mutual funds.
- Improve portfolio diversification by analyzing categories with stable Net AUM growth.
- Track investor redemption trends to identify potential market risks.
- Use correlation analysis to support data-driven investment strategies.
